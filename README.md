# Kepler Lab

Experiência web 3D, em pt-BR, para explorar a Via Láctea a partir da Terra, com conteúdo científico curado e citado.

- Escopo do produto: [`specs/product-spec.md`](./specs/product-spec.md)
- Plano de implementação: [`PLAN.md`](./PLAN.md)
- Regras para agentes e arquitetura: [`AGENTS.md`](./AGENTS.md)

## Desenvolvimento

Requer Node.js 22.12+ ou 24+.

```bash
npm install
npm run dev     # servidor local
npm test        # testes unitários (Vitest)
npm run build   # build de produção
npm run lint    # Oxlint
```
